------------------------------------------------------------
1. contextualize_query -- self-references become the user's name
------------------------------------------------------------
  'what is your age'                     -> "What is Alice's age?"
  "What is the user's age?"              -> "What is Alice's age?"
  'you like remote work?'                -> 'Does Alice like remote work?'

2. expand_query -- a broad query, grounded in the real KB schema
------------------------------------------------------------
Query: 'What jobs is Alice suitable for?'
  - What degrees does Alice have?
  - What skills does Alice possess?
  - What organizations has Alice worked at?
  - What courses has Alice taken?
  - What job postings has Alice applied to?
(5 sub-question(s) -- each targets a distinct schema facet)
